# 多功能桌面气象站

## 项目概述

基于 STM32F103C8T6 最小系统板的多功能桌面气象站，集成：
- **温湿度感知**：NTC 热敏电阻（温度）
- **光照感知**：光敏电阻（模拟量）
- **数据展示**：0.96 寸 OLED（I2C）
- **历史存储**：W25Q64 外部 Flash（SPI）
- **用户交互**：两个按键（切换页面、保存记录、清空历史）
- **报警功能**：蜂鸣器在温度/光照超阈值时报警

## 引脚对照表

| 功能 | STM32 引脚 | 模块引脚 | 备注 |
|------|------------|----------|------|
| OLED SCL | PB8 | SCL | I2C1 |
| OLED SDA | PB9 | SDA | I2C1 |
| 按键 1 | PB1 | - | 切换页面 |
| 按键 2 | PB11 | - | 长按清空历史 |
| 蜂鸣器 | PB12 | - | 报警 |
| 光敏电阻 AO | **PA0** | AO | ADC1_IN0 |
| 热敏电阻 AO | **PA1** | AO | ADC1_IN1 |
| W25Q64 CS | **PA4** | CS | 软件控制 |
| W25Q64 SCK | **PA5** | SCK | SPI1 |
| W25Q64 MISO | **PA6** | MISO | SPI1 |
| W25Q64 MOSI | **PA7** | MOSI | SPI1 |
| 串口 TX | PA9 | - | USART1 |
| 串口 RX | PA10 | - | USART1 |

## 模块供电

- OLED：VCC -> 3.3V，单独供电可直接接板载 3V3
- 蜂鸣器：VCC -> 3.3V
- 光敏电阻 / 热敏电阻：VCC -> 3.3V
- W25Q64：VCC -> 3.3V（**注意 5V 会烧！**）

## 显示页设计

**第 1 页：实时数据**
```
T: 25.3 C     [温度]
L:  68%       [光照百分比]
H:  72%       [湿度占位]
12:34:56      [时间]
```

**第 2 页：当日统计**
```
Today:Max T 28 C
      Min T 21 C
Today:Max L 99%
      Min L 32%
```

**第 3 页：历史**
```
[0] 23.5C 80% 10:15
[1] 23.8C 78% 10:25
[2] ...
...

记录数: 28/100
```

按键 1：切换页面
按键 2：长按 2 秒清空历史

## 报警阈值

- 温度 > 40℃：蜂鸣器短叫 3 次
- 光照 > 95%：蜂鸣器短叫 1 次（刺眼）
- 光照 < 5%：蜂鸣器短叫 2 次（过暗）
