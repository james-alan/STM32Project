## 一、STM32是什么

### 1.1 名称含义

```
STM32 = ST公司 + M(Microcontroller) + 32(32位)
```

| 组成部分 | 含义 | 说明 |
|---------|------|------|
| ST | ST公司（意法半导体） | 芯片制造商 |
| M | Microcontroller（微控制器） | 即MCU/单片机 |
| 32 | 32位 | 对比51单片机是8位 |

- ST也推出过8位单片机 **STM8**
- STM32基于 **ARM Cortex-M内核** 开发

### 1.2 产业链关系

```
ARM公司 → 设计Cortex-M内核（只做IP，不生产实物）
   ↓ 授权
ST公司 → 完善外围电路 + 封装 → 生产STM32芯片
   ↓
其他厂商也可拿ARM内核做自己的芯片（如NXP、TI等）
```

> ARM是半导体知识产权(IP)提供商，通过授权收费盈利。全球超95%的智能手机和平板采用ARM架构。

### 1.3 应用领域

| 领域 | 应用举例 |
|------|---------|
| 智能车 | 循迹小车（读取传感器+驱动电机） |
| 无人机 | 读取陀螺仪/加速度计姿态数据，控制电机保持稳定 |
| 机器人 | PWM驱动舵机控制关节运动 |
| 无线通信 | 连接2.4G无线模块、蓝牙、WiFi |
| 物联网 | 无线通信+驱动继电器控制220V电路 |
| 工业控制 | PLC内部主控（拆解过国产PLC发现是STM32） |
| 娱乐产品 | 爱心流水灯等 |

## 二、ARM内核体系

### 2.1 Cortex系列分类

```
ARM处理器
├── 经典ARM处理器（ARM7/ARM9/ARM11）← 老架构
└── Cortex系列
    ├── Cortex-A（Application）→ 手机/电脑领域
    │   例：苹果A系列、高通骁龙、联发科、苹果M1
    ├── Cortex-R（Real-time）→ 高实时性场景
    │   例：硬盘控制器
    └── Cortex-M（Microcontroller）→ 单片机领域 ← STM32用这个
        型号：M0, M1, M3, M4, M7, M23, M33...
```

### 2.2 STM32系列对应的Cortex-M内核

| STM32系列 | Cortex-M内核 | 定位 |
|-----------|-------------|------|
| F0 | M0 | 入门级 |
| **F1（本课程）** | **M3** | 主流 |
| F3 | M4 | 主流+DSP |
| F4 | M4 | 高性能 |
| F7 | M7 | 高性能 |
| H7 | M7+M4双核 | 旗舰 |

## 三、STM32F103C8T6芯片参数

### 3.1 核心参数

| 参数 | 值 |
|------|-----|
| 系列 | STM32F1 主流系列 |
| 内核 | ARM Cortex-M3 |
| 主频 | 72MHz |
| RAM（运行内存） | 20KB（SRAM） |
| ROM（程序存储） | 64KB（Flash闪存） |
| 供电电压 | 2.0V ~ 3.6V（标准3.3V） |
| 封装 | LQFP48（48引脚） |

> **重要**：STM32是3.3V供电，不能直接接5V！51单片机是5V供电，这点不同。如需5V输入，需加稳压芯片（如XC6204、AMS1117等）。

### 3.2 命名规则

```
STM32 F 103 C 8 T 6
  │   │  │   │ │ │ └─ 温度范围：6=-40~85℃
  │   │  │   │ │ └─── 封装：T=LQFP
  │   │  │   │ └───── Flash容量：8=64KB
  │   │  │   └─────── 引脚数：C=48脚
  │   │  └─────────── 子型号：103=增强型
  │   └────────────── 类型：F=通用型（Foundation）
  └────────────────── 品牌：32位ARM微控制器
```

**常见变体**：STM32F103RCT6 → 64脚、256K Flash

## 四、片上外设资源全景

### 4.1 外设总览表

| 外设缩写 | 全称/功能 | 总线 | 要点 |
|---------|----------|------|------|
| **NVIC** | 嵌套向量中断控制器 | 内核 | 管理中断、配置优先级 |
| **SysTick** | 系统滴答定时器 | 内核 | 给OS提供时基，也可做延时 |
| **RCC** | 复位和时钟控制 | AHB | 配置时钟+使能各模块时钟（操作前必须先开时钟！） |
| **GPIO** | 通用IO口 | APB2 | 点灯、按键等基本功能 |
| **AFIO** | 复用IO口 | APB2 | 复用功能重映射+中断端口配置 |
| **EXTI** | 外部中断 | — | 引脚电平变化触发中断 |
| **TIM** | 定时器 | APB1/2 | 最强大外设：定时中断/测频率/PWM/编码器 |
| **ADC** | 12位模数转换器 | APB2 | 读模拟电压，无需外接ADC芯片 |
| **DMA** | 直接存储器访问 | AHB | CPU的小秘书，自动搬运数据 |
| **USART** | 同步/异步串口 | APB1/2 | 串口通信（常用异步UART模式） |
| **I2C** | I2C总线控制器 | APB1 | 硬件输出I2C时序 |
| **SPI** | SPI总线控制器 | APB1/2 | 硬件输出SPI时序 |
| **CAN** | CAN总线 | APB1 | 汽车领域常用 |
| **USB** | USB控制器 | APB1 | 模拟鼠标/U盘等设备 |
| **RTC** | 实时时钟 | — | 年月日时分秒计时，可接备份电池掉电运行 |
| **CRC** | CRC校验单元 | AHB | 硬件数据校验 |
| **PWR** | 电源控制 | APB1 | 睡眠/停止/待机等低功耗模式 |
| **BKP** | 备份寄存器 | APB1 | 掉电后由备用电池保持数据 |
| **IWDG** | 独立看门狗 | — | 防死机，超时自动复位 |
| **WWDG** | 窗口看门狗 | APB1 | 精确时间窗口的看门狗 |

> ⚠️ C8T6型号**没有**以下外设：DAC、SDIO、FSMC、USB-OTG。使用前务必查阅数据手册确认。

### 4.2 C8T6实际外设数量（来自数据手册）

| 外设 | 数量 |
|------|------|
| 通用定时器(TIM2/3/4) | 3个 |
| 高级定时器(TIM1) | 1个 |
| 基本定时器 | 0个 |
| SPI | 2个 |
| I2C | 2个 |
| USART | 3个 |
| USB | 1个 |
| CAN | 1个 |
| IO口 | 37个 |
| 12位ADC(10通道) | 2个 |

## 五、系统架构（总线结构）

### 5.1 总线层次

```
          Cortex-M3 内核
          ┌──────┼──────┐
    ICode总线  DCode总线  System总线
       │          │          │
    Flash       Flash     SRAM / FSMC
   (取指令)    (取数据)
                          │
                    AHB系统总线 (72MHz)
                    ┌─────┼─────┐
                  RCC   SDIO   DMA
                          │
                    ┌──────┴──────┐
                Bridge1       Bridge2
                    │              │
              APB2 (72MHz)   APB1 (36MHz)
              ┌──┼──┐        ┌──┼──┐
            GPIO  ADC      TIM2~4  USART2~3
            TIM1  SPI1     I2C     SPI2
            USART1         PWR     BKP
            AFIO  EXTI     DAC     ...
```

| 总线 | 频率 | 连接的外设 |
|------|------|-----------|
| AHB | 72MHz | RCC, SDIO, DMA |
| APB2 | 72MHz | GPIO, TIM1, ADC, USART1, SPI1, AFIO, EXTI |
| APB1 | 36MHz | TIM2~4, USART2~3, I2C, SPI2, PWR, BKP |

> **规则**：GPIO和重要的"1号外设"挂在APB2，次要的挂APB1。实际使用中性能差异不太明显。

### 5.2 DMA的作用

```
传统方式：外设ADC → 中断 → CPU → 搬运数据到内存（CPU频繁被打断）
DMA方式：  外设ADC → DMA请求 → DMA自动搬运 → CPU干别的事
```

DMA拥有和CPU同等的总线控制权，适合反复搬运大量数据的场景（如ADC连续转换）。

## 六、引脚定义

### 6.1 C8T6引脚分类

| 颜色标记 | 类别 | 说明 |
|---------|------|------|
| 🔴 红色 | 电源引脚 | VDD(3.3V)、VSS(GND)、VBAT |
| 🔵 蓝色 | 最小系统引脚 | 晶振(OSC)、复位(NRST)、BOOT |
| 🟢 绿色 | IO口/功能口 | GPIO和复用功能 |

### 6.2 关键引脚速查

| 引脚号 | 名称 | 功能 |
|--------|------|------|
| 1 | VBAT | 备用电池供电（RTC+BKP掉电保持） |
| 2 | PC13 | GPIO / 侵入检测 / RTC输出 |
| 3-4 | PC14,PC15 | GPIO / 32.768kHz RTC晶振 |
| 5-6 | OSC_IN,OSC_OUT | 8MHz主晶振 |
| 7 | NRST | 复位引脚（低电平复位） |
| 8-9 | VSSA,VDDA | 模拟部分电源 |
| 20 | PB2/BOOT1 | GPIO / 启动配置1 |
| 23-24 | VSS_1,VDD_1 | 主电源1 |
| 34 | PA13/SWDIO | 调试数据线 |
| 37 | PA14/SWCLK | 调试时钟线 |
| 44 | BOOT0 | 启动配置0 |

### 6.3 FT引脚（5V容忍）

- 引脚定义中标有 **FT** 的：可容忍5V输入
- 没有FT的：只能接受3.3V，接5V需加电平转换电路

### 6.4 SWD调试引脚

| 引脚 | SWD功能 | JTAG功能 |
|------|---------|----------|
| PA13 | SWDIO（数据） | JTMS |
| PA14 | SWCLK（时钟） | JTCK |
| PA15 | — | JTDI |
| PB3 | — | JTDO |
| PB4 | — | JNTRST |

> ST-Link使用SWD方式，只需PA13+PA14两根线。PA15/PB3/PB4可通过程序配置为普通IO口（需显式配置，默认是调试功能）。

## 七、启动配置（BOOT引脚）

### 7.1 三种启动模式

| BOOT1 | BOOT0 | 启动模式 | 用途 |
|-------|-------|---------|------|
| X | 0 | **主闪存存储器**（Flash） | **最常用**：正常执行程序 |
| 0 | 1 | **系统存储器** | 串口下载（BootLoader模式） |
| 1 | 1 | **内置SRAM** | 程序调试（较少用） |

### 7.2 串口下载的使用场景

1. **救急**：不小心把PA13/PA14/PA15/PB3/PB4全配成了普通IO口，调试口没了
2. **无调试器**：手头没有ST-Link或J-Link

配置方法：BOOT1=0, BOOT0=1 → 上电复位 → 进入BootLoader → 用串口下载

> BOOT引脚的值在**上电复位后第4个SYSCLK上升沿**被锁定，之后可当作普通IO口使用（如PB2/BOOT1）。

## 八、最小系统电路

### 8.1 最小系统组成

```
STM32最小系统电路
├── 供电电路
│   ├── VDD → 3.3V（所有VDD都接3.3V）
│   ├── VSS → GND（所有VSS都接GND）
│   ├── 滤波电容（每个电源口并联0.1μF）
│   └── VBAT → 备用电池3V 或 直接接3.3V
├── 晶振电路
│   ├── 8MHz主晶振 + 2×20pF起振电容 → OSC_IN/OSC_OUT
│   └── 32.768kHz RTC晶振 + 2×20pF → PC14/PC15（可选）
├── 复位电路
│   └── 10KΩ上拉电阻 + 0.1μF电容 + 手动按键 → NRST
├── BOOT配置
│   └── 跳线帽/拨码开关 → BOOT0, BOOT1（切换GND/3.3V）
└── 下载接口
    └── SWDIO(PA13) + SWCLK(PA14) + 3.3V + GND
```

### 8.2 关键元件说明

| 元件 | 作用 |
|------|------|
| 8MHz晶振 | 经PLL倍频得72MHz主时钟 |
| 32.768kHz晶振 | 2^15分频=1秒，给RTC提供精准时基 |
| 20pF起振电容 | 配合晶振起振 |
| 4.7μF+0.1μF滤波电容 | 稳定供电电压 |
| XC6204/AMS1117 | 5V→3.3V稳压芯片 |
| 跳线帽 | 配置BOOT高低电平 |

### 8.3 最小系统板实物识别

| 位置 | 元件 |
|------|------|
| 中央 | STM32F103C8T6黑色芯片 |
| 左 | BOOT跳线帽 ×2 |
| 左下 | 复位按键 |
| 左中 | USB接口（通信+供电） |
| 右 | 8MHz金属晶振 |
| 右 | 32.768kHz黑色RTC晶振 |
| 右 | PWR电源灯(红) + PC13测试灯 |
| 最右 | SWD调试接口 |
| 背面 | XC6204 3.3V稳压芯片 |

## 九、核心要点总结

1. **STM32 = ARM Cortex-M3内核 + ST公司的外围电路**，72MHz主频，3.3V供电
2. **RCC使能时钟是第一步**：外设默认时钟关闭，操作前必须先使能
3. **APB2(72MHz)挂重要外设**（GPIO/TIM1/ADC/USART1），**APB1(36MHz)挂次重要外设**
4. **DMA = CPU的小秘书**：自动搬运数据，CPU解放出来做更重要的事
5. **FT引脚可容忍5V**，非FT引脚只能接3.3V
6. **SWD调试只需PA13+PA14**，比JTAG省3个引脚
7. **BOOT0=0,BOOT1=X → Flash启动**（最常用）；**BOOT0=1,BOOT1=0 → 串口下载**
8. **不要把所有调试口都配成IO口**，否则只能用串口救急
9. **C8T6没有DAC/SDIO/FSMC/USB-OTG**，查数据手册确认外设是否存在
