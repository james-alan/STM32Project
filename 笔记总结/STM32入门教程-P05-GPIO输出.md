## 一、GPIO概述

### 1.1 基本概念

```
GPIO = General Purpose Input Output（通用输入输出口，即IO口）
```

- 挂载在 **APB2** 总线上（72MHz）
- 每个GPIO模块有**16个引脚**（0~15）
- 命名：PA0~PA15, PB0~PB15, PC0~PC15...
- 引脚电平：0V（低电平/0）、3.3V（高电平/1）
- **FT引脚**可容忍5V输入，但输出最大仅3.3V

### 1.2 八种工作模式

| 模式 | 类型 | 用途 |
|------|------|------|
| **浮空输入** | 输入 | 外部必须接入驱动源，不能悬空 |
| **上拉输入** | 输入 | 悬空默认高电平 |
| **下拉输入** | 输入 | 悬空默认低电平 |
| **模拟输入** | 输入 | ADC专用，关闭数字输入 |
| **开漏输出** | 输出 | 仅低电平有驱动，可输出5V（外接上拉） |
| **推挽输出** | 输出 | 高低电平均有强驱动能力 |
| **复用开漏输出** | 输出（外设控制） | 片上外设控制的开漏输出 |
| **复用推挽输出** | 输出（外设控制） | 片上外设控制的推挽输出 |

## 二、GPIO内部电路结构

### 2.1 位结构图总览

```
         ┌────────────── 输入部分 ──────────────┐
IO引脚 → 保护二极管 → 上拉/下拉电阻 → 施密特触发器 → 输入数据寄存器
         │              ↑可配置          ↓整形      ↓程序读取
         │                           复用功能输入(外设)
         │                           模拟输入(ADC)
         │
         └────────────── 输出部分 ──────────────┐
         输出数据寄存器 → 输出控制 → PMOS/NMOS → IO引脚
         位设置/清除寄存器  ↑
                         片上外设(复用输出)
```

### 2.2 各组件功能

| 组件 | 功能 |
|------|------|
| **保护二极管** | 限幅：输入>3.3V时上管导通→电流流入VDD；输入<0V时下管导通→电流流出VSS |
| **上拉/下拉电阻** | 给悬空引脚提供默认电平（弱上拉/弱下拉，不影响正常输入） |
| **施密特触发器** | 波形整形：两阈值（上限/下限），消除抖动，产生干净的方波 |
| **PMOS + NMOS** | 推挽：两管均有效；开漏：仅NMOS有效 |
| **位设置/清除寄存器** | 单独控制某一位，不影响其他位，替代 `|=` `&=` 操作 |

### 2.3 输入模式详解

| 模式 | 上拉电阻 | 下拉电阻 | 悬空默认电平 |
|------|---------|---------|------------|
| 上拉输入 | ✅ 导通 | ❌ 断开 | 高电平 |
| 下拉输入 | ❌ 断开 | ✅ 导通 | 低电平 |
| 浮空输入 | ❌ 断开 | ❌ 断开 | **不确定**（必须接驱动源） |

### 2.4 输出模式详解

| 模式 | PMOS | NMOS | 特点 |
|------|------|------|------|
| **推挽输出** | ✅ | ✅ | 高低电平均有驱动，STM32完全控制IO口 |
| **开漏输出** | ❌ | ✅ | 仅低电平有驱动；高电平为高阻态；可外接上拉输出5V |
| **关闭** | ❌ | ❌ | 输入模式专用 |

## 三、寄存器速查

| 寄存器 | 位数 | 功能 |
|--------|------|------|
| GPIOx_CRL | 32位（低8端口×4位） | 配置端口0~7的模式 |
| GPIOx_CRH | 32位（高8端口×4位） | 配置端口8~15的模式 |
| GPIOx_IDR | 低16位有效 | 输入数据寄存器（只读） |
| GPIOx_ODR | 低16位有效 | 输出数据寄存器 |
| GPIOx_BSRR | 低16位=置位，高16位=复位 | 位设置/清除寄存器 |
| GPIOx_BRR | 低16位有效 | 位清除寄存器 |
| GPIOx_LCKR | — | 端口配置锁定寄存器 |

## 四、外围硬件电路

### 4.1 LED驱动

```
低电平驱动（推荐）:          高电平驱动:
    3.3V                        IO口
     │                           │
    [LED]                      [R]
     │                           │
    [R]限流电阻                 [LED]
     │                           │
    IO口                        GND
  IO=0亮, IO=1灭              IO=1亮, IO=0灭
```

> 推荐低电平驱动：多数芯片低电平驱动能力强，可避免"高低电平打架"

### 4.2 蜂鸣器驱动

| 类型 | 特点 | 驱动方式 |
|------|------|---------|
| **有源蜂鸣器**（本课程用） | 内置振荡源，通电即响 | 三极管开关 |
| 无源蜂鸣器 | 需外部提供振荡脉冲 | PWM控制 |

三极管开关电路：
- **PNP**：基极低电平导通（接上端）
- **NPN**：基极高电平导通（接下端）

## 五、库函数操作GPIO输出

### 5.1 三步走

| 步骤 | 函数 | 说明 |
|------|------|------|
| 1. 使能时钟 | `RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOx, ENABLE)` | 所有GPIO在APB2上 |
| 2. 配置模式 | `GPIO_Init(GPIOx, &GPIO_InitStructure)` | 结构体配置 |
| 3. 输出电平 | `GPIO_SetBits()` / `GPIO_ResetBits()` | 置高/置低 |

### 5.2 结构体参数

```c
GPIO_InitTypeDef GPIO_InitStructure;

GPIO_InitStructure.GPIO_Mode  = GPIO_Mode_Out_PP;  // 推挽输出
GPIO_InitStructure.GPIO_Pin   = GPIO_Pin_0;        // 引脚编号
GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;  // 输出速度

GPIO_Init(GPIOA, &GPIO_InitStructure);
```

## 六、关键要点总结

1. **GPIO在APB2上**，使用前必须 `RCC_APB2PeriphClockCmd` 使能时钟
2. **推挽输出**最常用，高低电平均有强驱动
3. **开漏输出**用于I2C通信或输出5V电平（外接上拉电阻）
4. **上拉/下拉输入**避免引脚悬空导致电平不确定
5. **模拟输入**是ADC专用，关闭数字电路
6. GPIO输出速度一般选50MHz
7. LED推荐**低电平驱动**（多数芯片低电平驱动力强）
8. 有源蜂鸣器 = 通电即响，像点灯一样简单
