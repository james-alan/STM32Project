## 2. 本节目标

实现内部 FLASH 参数保存、读取和芯片容量/UID 读取，并用 ST-Link 工具验证。

## 3. 核心概念

| 概念 | 字幕整理后的含义 |
|---|---|
| MyFlash 层 | 封装 FLASH 基础读、擦、写。 |
| Store 层 | 管理应用参数和保存策略。 |
| 掉电保存 | 写入内部 FLASH 后断电仍可恢复。 |
| 芯片 ID | 从电子签名区域读取容量和 UID。 |
| 调试辅助 | STLINK Utility 能直接查看地址内容。 |

## 4. 硬件/外设/协议要点

| 要点 | 说明 |
|---|---|
| 按键 | 修改参数或触发保存。 |
| OLED | 显示参数、容量和 UID。 |
| ST-Link | 连接 Utility 查看内部 FLASH。 |

## 5. 配置步骤或实验流程

1. 建立 MyFlash，实现读取、擦除、编程。
2. 建立 Store，定义掉电保存参数数组。
3. 初始化时从指定 FLASH 页读回参数。
4. 参数改变后擦除目标页并重新写入。
5. 读取芯片容量和 UID 固定地址并显示。

## 6. 代码/函数要点

| 名称 | 用法/意义 |
|---|---|
| MyFlash_ReadWord / ReadHalfWord | 指针读取指定地址。 |
| MyFlash_ErasePage | 擦除保存页。 |
| MyFlash_ProgramHalfWord | 按半字写入。 |
| Store_Init / Store_Save | 参数保存接口。 |
| Flash Size / UID | 器件电子签名读取。 |

## 8. 常见坑

- 保存页地址必须避开程序范围。
- 擦除会清空整页，页内数据要整体管理。
- 地址加偏移要先括号计算再按类型读取。
