## 一、硬件接线

### 1.1 引脚连接表

| STM32 引脚 | 方向 | USB转串口模块 | 说明 |
|:---:|:---:|:---:|:---|
| PA9 | TX → | RXD | STM32 发送，接串口模块接收 |
| PA10 | RX ← | TXD | STM32 接收，接串口模块发送 |
| GND | ↔ | GND | **共地**（必须接，否则电平无参考） |
| — | — | 3V3/VCC | 跳线帽插 3V3，选择 3.3V TTL 电平 |

### 1.2 接线要点

```
┌─────────────┐         ┌──────────────────┐
│  STM32      │         │  USB转串口(CH340) │
│             │         │                   │
│  PA9 (TX) ──┼────────►│  RXD              │
│  PA10 (RX) ◄─┼────────│  TXD              │
│  GND ───────┼─────────│  GND              │
│             │         │  VCC─3V3(跳线帽)   │
└─────────────┘         └──────────────────┘
     ▲                        ▲
     │ ST-Link                │ USB
     ▼                        ▼
  ┌──────────────────────────────┐
  │         电  脑   USB         │
  └──────────────────────────────┘
```

> **关键**: TX ↔ RX 交叉连接！别接反了。两边各自独立供电，VCC 不接。

### 1.3 驱动验证

设备管理器 → 端口 → 查看 `CH340` 是否正常（无感叹号 + 有 COM 号）。

## 二、USART 初始化流程

### 2.1 初始化四步走

```
┌──────────────┐
│ ① 开启时钟    │  RCC_APB2PeriphClockCmd(USART1 + GPIOA)
└──────┬───────┘
       ▼
┌──────────────┐
│ ② GPIO 初始化 │  TX → GPIO_Mode_AF_PP (复用推挽输出)
│              │  RX → GPIO_Mode_IN_FLOATING (浮空输入)
└──────┬───────┘
       ▼
┌──────────────┐
│ ③ USART 配置 │  USART_InitStructure: 波特率、数据位、停止位...
└──────┬───────┘
       ▼
┌──────────────┐
│ ④ 使能 USART │  USART_Cmd(USART1, ENABLE)
│   [+中断可选] │  如需接收中断 → USART_ITConfig + NVIC
└──────────────┘
```

### 2.2 初始化代码

```c
// Serial.c

#include "stm32f10x.h"

void Serial_Init(void)
{
    // ========== ① 开启时钟 ==========
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_USART1, ENABLE);
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);

    // ========== ② GPIO 初始化 ==========
    GPIO_InitTypeDef GPIO_InitStructure;

    // TX (PA9) — 复用推挽输出
    GPIO_InitStructure.GPIO_Mode  = GPIO_Mode_AF_PP;       // 复用推挽输出
    GPIO_InitStructure.GPIO_Pin   = GPIO_Pin_9;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOA, &GPIO_InitStructure);

    // RX (PA10) — 浮空输入（或上拉输入）
    GPIO_InitStructure.GPIO_Mode  = GPIO_Mode_IN_FLOATING; // 浮空输入
    GPIO_InitStructure.GPIO_Pin   = GPIO_Pin_10;
    GPIO_Init(GPIOA, &GPIO_InitStructure);

    // ========== ③ USART 配置 ==========
    USART_InitTypeDef USART_InitStructure;
    USART_InitStructure.USART_BaudRate            = 9600;               // 波特率
    USART_InitStructure.USART_HardwareFlowControl = USART_HardwareFlowControl_None; // 无流控
    USART_InitStructure.USART_Mode                = USART_Mode_Tx | USART_Mode_Rx;  // 收发模式
    USART_InitStructure.USART_Parity              = USART_Parity_No;    // 无校验
    USART_InitStructure.USART_StopBits            = USART_StopBits_1;   // 1 停止位
    USART_InitStructure.USART_WordLength          = USART_WordLength_8b; // 8 数据位
    USART_Init(USART1, &USART_InitStructure);

    // ========== ④ 使能 ==========
    USART_Cmd(USART1, ENABLE);
}
```

## 三、关键库函数速查

| 函数 | 功能 | 说明 |
|:---|:---|:---|
| `USART_Init()` | 初始化 USART | 结构体配置参数 |
| `USART_Cmd()` | 使能/失能 USART | |
| `USART_SendData(USARTx, data)` | 发送一个字节 | 写 DR 寄存器 |
| `USART_ReceiveData(USARTx)` | 接收一个字节 | 读 DR 寄存器 |
| `USART_GetFlagStatus(USARTx, flag)` | 获取标志位状态 | TXE（发送空）、RXNE（接收非空）等 |
| `USART_ITConfig()` | 配置中断 | 接收中断等 |
| `USART_DMACmd()` | 开启 USART→DMA 通道 | DMA 传输用 |

> **常用标志位**: `USART_FLAG_TXE`（发送数据寄存器空）、`USART_FLAG_RXNE`（接收数据寄存器非空）、`USART_FLAG_TC`（发送完成）

## 四、串口发送函数封装（纯软件层）

### 4.1 发送一个字节

```c
/**
 * @brief  串口发送一个字节
 * @param  Byte  要发送的字节数据
 */
void Serial_SendByte(uint8_t Byte)
{
    USART_SendData(USART1, Byte);                        // 写入 DR
    while (USART_GetFlagStatus(USART1, USART_FLAG_TXE) == RESET); // 等待发送完成
}
```

### 4.2 发送数组

```c
/**
 * @brief  串口发送一个数组
 * @param  Array  数组首地址（指针）
 * @param  Length 数组长度
 */
void Serial_SendArray(uint8_t *Array, uint16_t Length)
{
    uint16_t i;
    for (i = 0; i < Length; i++)
    {
        Serial_SendByte(Array[i]);
    }
}
```

### 4.3 发送字符串

```c
/**
 * @brief  串口发送字符串
 * @param  String  字符串指针（以 '\0' 结尾）
 */
void Serial_SendString(char *String)
{
    uint8_t i;
    for (i = 0; String[i] != '\0'; i++)
    {
        Serial_SendByte(String[i]);
    }
}
```

### 4.4 发送数字（自己写转换）

```c
/**
 * @brief  串口发送一个数字（转为十进制字符串发送）
 * @param  Number 要发送的数字
 * @param  Length 数字位数
 */
void Serial_SendNumber(uint32_t Number, uint8_t Length)
{
    uint8_t i;
    for (i = 0; i < Length; i++)
    {
        // 逐位取数字（从高位到低位）
        Serial_SendByte('0' + Number / Power_X(10, Length - i - 1) % 10);
    }
}
```

## 五、printf 重定向（三种方法）

### 方法对比

| 方法 | 原理 | 优点 | 缺点 |
|:---|:---|:---|:---|
| **① 微库 + fputc** | 重写 `fputc`，勾选 Use MicroLIB | 最简单，原生 `printf` 直接可用 | 只能重定向到一个串口 |
| **② sprintf 中转** | `sprintf` 打印到字符串 → 串口发送 | 多个串口可独立使用 | 每次需定义缓冲区 |
| **③ 封装 serial_printf** | `vsprintf` + 可变参数宏 | 一次封装，全局通用 | 需要理解可变参数 |

### 方法一：微库 + fputc（推荐首选）

```c
// 勾选 Target → Use MicroLIB

#include <stdio.h>

/**
 * @brief  重定向 fputc，使 printf 输出到串口 1
 * @note   必须勾选 Use MicroLIB（Target 选项卡）
 */
int fputc(int ch, FILE *f)
{
    Serial_SendByte(ch);    // 通过串口发出
    return ch;
}
```

使用方法：

```c
printf("Hello World\r\n");
printf("num = %d\r\n", 123);
```

### 方法二：sprintf 中转（多串口场景）

```c
#include <stdio.h>

char string[100];
sprintf(string, "num = %d\r\n", 123);
Serial_SendString(string);
```

### 方法三：封装 serial_printf（可变参数）

```c
#include <stdarg.h>

/**
 * @brief  串口格式化打印（支持可变参数，类似 printf）
 * @param  format  格式化字符串
 * @param  ...     可变参数列表
 */
void Serial_Printf(char *format, ...)
{
    char string[100];               // 输出缓冲区
    va_list arg;                    // 可变参数列表变量
    va_start(arg, format);          // 从 format 之后开始取参数
    vsprintf(string, format, arg);  // 格式化到 string
    va_end(arg);                    // 释放参数列表
    Serial_SendString(string);      // 串口发送
}
```

## 六、Hex 模式 vs 文本模式 & 字符编码

### 6.1 数据显示模式

| 模式 | 别称 | 原理 | 示例 |
|:---|:---|:---|:---|
| **HEX 模式** | 十六进制/原始数据 | 直接显示接收到的数据本身 | `0x41` 显示为 `41` |
| **文本模式** | 字符模式 | 通过字符集编码/解码后显示 | `0x41` 显示为 `A` |

### 6.2 数据发送与接收的转换流程

```
发送方                                    接收方
┌──────────┐                            ┌──────────────┐
│ 字符 'A' │──→ 编码(ASCII) ──→ 0x41    │              │
└──────────┘                            │              │
                                        │  线路传输 0x41 │
┌──────────┐                            │              │
│ 数据 0x41│────────────────────────────│              │
└──────────┘                            └──────┬───────┘
                                               │
                          ┌────────────────────┼────────────────────┐
                          ▼                                         ▼
                    ┌──────────┐                              ┌──────────┐
                    │ HEX 显示 │                              │ 文本显示  │
                    │   41     │                              │ 解码→'A' │
                    └──────────┘                              └──────────┘
```

### 6.3 ASCII 字符集（速查）

| 数据范围 | 含义 | 示例 |
|:---|:---|:---|
| `0x00` | 空字符（NULL），字符串结束标志 | `'\0'` |
| `0x00~0x1F` | 控制字符（退格、换行、换页等） | `\n`=`0x0A`, `\r`=`0x0D` |
| `0x30~0x39` | 字符数字 `0`~`9` | `'0'`=`0x30` |
| `0x41~0x5A` | 大写字母 `A`~`Z` | `'A'`=`0x41` |
| `0x61~0x7A` | 小写字母 `a`~`z` | `'a'`=`0x61` |

### 6.4 Unicode 字符集体系

| 编码 | 范围 | 说明 |
|:---|:---|:---|
| **GB2312** | 简体中文 | 双字节编码 |
| **GBK** | 扩展中文 | GB2312 的超集，Windows 默认 |
| **GB18030** | 最新国标 | 覆盖所有 Unicode |
| **Unicode (UTF-8)** | 全球统一 | 变长编码，最通用 |

## 七、汉字乱码解决方案

```
┌─────────────────────────────────────────────────────┐
│              乱码根源：编码不匹配！                    │
│                                                      │
│   Keil 源文件编码  ≠  串口助手编码  →  乱码           │
└─────────────────────────────────────────────────────┘
```

### 方案一：全程 UTF-8

1. Keil 文件编码选 **UTF-8**
2. Keil → Options → C/C++ → Misc Controls 添加：`--no-multibyte-chars`
3. 串口助手编码选 **UTF-8**

### 方案二：全程 GB2312

1. Keil → Edit → Configuration → Encoding 选 **GB2312**
2. **删除中文 → 关闭文件 → 重新打开**（字体变为宋体才生效）
3. 串口助手编码选 **GBK**（Windows 默认）

### 方案三：批量转码

资料包中提供转码软件，可批量转换文件编码（记得关只读）。

> **建议**: 新工程直接用 UTF-8，全球化兼容性最好。

## 九、知识总结

```
                    STM32 USART 串口通信

    ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
    │  硬件接线     │     │  软件初始化   │     │  数据收发     │
    ├──────────────┤     ├──────────────┤     ├──────────────┤
    │ TX ↔ RXD     │     │ ① 开时钟     │     │ SendByte()   │
    │ RX ↔ TXD     │ ──→ │ ② GPIO配置   │ ──→ │ SendArray()  │
    │ GND ↔ GND    │     │ ③ USART配置  │     │ SendString() │
    │ 3.3V 电平    │     │ ④ 使能       │     │ printf()     │
    └──────────────┘     └──────────────┘     └──────────────┘
                                │
                    ┌───────────┴───────────┐
                    ▼                       ▼
            ┌──────────────┐        ┌──────────────┐
            │  HEX 模式     │        │  文本模式     │
            │  原始数据     │        │  ASCII/UTF-8 │
            └──────────────┘        └──────────────┘
```

### 常见坑点

| 坑 | 原因 | 解决 |
|:---|:---|:---|
| 通信无数据 | TX/RX 没交叉连接 或 没共地 | 检查接线，GND 必接 |
| 中文乱码 | Keil 编码 ≠ 串口助手编码 | UTF-8 统一 或 GB2312 统一 |
| 发送太快丢数据 | 没等 TXE 标志 | `while(TXE==RESET);` 等待 |
| `printf` 没输出 | 没勾 Use MicroLIB | Target → Use MicroLIB |
| 编译器报错 C语言汉字 | UTF-8 多字节问题 | 加 `--no-multibyte-chars` |
