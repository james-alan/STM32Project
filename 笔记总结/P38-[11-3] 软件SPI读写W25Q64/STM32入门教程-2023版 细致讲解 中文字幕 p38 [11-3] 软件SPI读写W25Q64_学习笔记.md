## 2. 本节目标

用 GPIO 软件模拟 SPI，实现 W25Q64 的 ID 读取、擦除、写入和读回验证。

## 3. 核心概念

| 概念 | 字幕整理后的含义 |
|---|---|
| 软件 SPI | 用 GPIO 手动控制 SCK/MOSI/CS 并采样 MISO。 |
| 交换字节 | SPI 每发一个字节同时读回一个字节。 |
| 指令封装 | W25Q64 操作由指令码、地址和数据组成。 |
| 读写验证 | 先读 ID，再写入固定数据并读回。 |

## 4. 硬件/外设/协议要点

| 要点 | 说明 |
|---|---|
| CS/SCK/MOSI/MISO | 软件 SPI 引脚需与代码一致。 |
| W25Q64 | 被测试 Flash。 |
| OLED | 显示 ID、W、R。 |

## 5. 配置步骤或实验流程

1. MySPI_Init 配置 GPIO。
2. Start 拉低 CS，Stop 拉高 CS。
3. SwapByte 交换 8 位。
4. ReadID 读取返回值。
5. WriteEnable 后 SectorErase。
6. WaitBusy 后 PageProgram。
7. 再 WaitBusy 后 ReadData 比较。

## 6. 代码/函数要点

| 名称 | 用法/意义 |
|---|---|
| MySPI_SwapByte | 软件 SPI 核心函数。 |
| W25Q64_ReadID | 验证通信。 |
| W25Q64_SectorErase | 擦除目标扇区。 |
| W25Q64_PageProgram | 写入数据。 |
| W25Q64_ReadData | 读回数据。 |

## 8. 常见坑

- CS 范围要覆盖完整指令。
- 写入/擦除前必须 WriteEnable。
- 擦写后要等 BUSY 清零。
