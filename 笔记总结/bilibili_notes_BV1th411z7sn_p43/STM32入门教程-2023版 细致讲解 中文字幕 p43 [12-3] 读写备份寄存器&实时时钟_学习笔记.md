## 2. 本节目标

完成 BKP 读写和 RTC 实时时钟代码，把时间戳与日期显示结合。

## 3. 核心概念

| 概念 | 字幕整理后的含义 |
|---|---|
| 初始化标志 | 用 BKP 避免每次复位重设 RTC。 |
| 时间保持 | VBAT 供电时 RTC 主电源断开仍计时。 |
| 时间转换 | RTC 保存秒计数，应用层转日期时间。 |
| 实验验证 | 复位、断电、再上电观察时间是否继续。 |

## 4. 硬件/外设/协议要点

| 要点 | 说明 |
|---|---|
| 按键 | BKP 实验触发写入。 |
| VBAT | 验证备份域保持。 |
| OLED | 显示 BKP 数据和 RTC 时间。 |

## 5. 配置步骤或实验流程

1. BKP：允许备份域访问，按键写入，再读出显示。
2. RTC：检查 BKP 标志，未初始化则配置时钟和初始时间。
3. 已初始化则跳过设置，只等待同步后读取。
4. 主循环读取 RTC_GetCounter 并转换日期时间。
5. 显示时间、秒计数和预分频值。

## 6. 代码/函数要点

| 名称 | 用法/意义 |
|---|---|
| BKP_WriteBackupRegister / ReadBackupRegister | 备份寄存器读写。 |
| RTC_GetCounter / SetCounter | 读写 RTC 秒计数。 |
| MyRTC_Init | RTC 初始化封装。 |
| TimeStamp_ConvUnixToDate | 时间戳转日期逻辑。 |

## 8. 常见坑

- 没有 VBAT 时掉电不能保持。
- 首次初始化和后续复位要分开。
- 设置 RTC 后要等待写操作完成。
