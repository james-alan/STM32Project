## 2. 本节目标

理解 PWR 电源控制、备份域和低功耗模式基础。

## 3. 核心概念

| 概念 | 字幕整理后的含义 |
|---|---|
| PWR | 管理备份域访问、电压监测和低功耗模式。 |
| 睡眠模式 | CPU 停止，外设可继续运行。 |
| 停止模式 | 关闭更多时钟，功耗更低，醒来需恢复系统时钟。 |
| 待机模式 | 功耗最低，醒来类似复位。 |

## 4. 硬件/外设/协议要点

| 要点 | 说明 |
|---|---|
| 按键/唤醒引脚 | 用于唤醒。 |
| OLED/LED | 观察进入或唤醒状态。 |
| PWR 外设 | 需开启时钟后配置。 |

## 5. 配置步骤或实验流程

1. 开启 PWR 时钟。
2. 需要访问备份域时使能备份域访问。
3. 按目标选择睡眠、停止或待机。
4. 配置唤醒源。
5. 进入前处理外设状态，醒来后恢复必要时钟。

## 6. 代码/函数要点

| 名称 | 用法/意义 |
|---|---|
| PWR_BackupAccessCmd | 控制备份域写访问。 |
| PWR_EnterSTOPMode | 进入停止模式。 |
| PWR_EnterSTANDBYMode | 进入待机模式。 |
| __WFI | 等待中断，常用于睡眠。 |

## 8. 常见坑

- 低功耗要同时考虑唤醒源和醒后状态。
- 停止模式醒后系统时钟可能要重配。
- 待机醒来不能期待普通变量保持。
