## 2. 本节目标

把 MPU6050 底层通信从软件 I2C 替换为硬件 I2C，保持上层接口不变。

## 3. 核心概念

| 概念 | 字幕整理后的含义 |
|---|---|
| 接口替换 | 只换底层通信，上层 Init/GetData 尽量不改。 |
| I2C2 | 视频选择 PB10/PB11 对应的 I2C2。 |
| 事件流程 | 读写按硬件 I2C 事件顺序等待。 |
| 封装隔离 | 底层实现变化不影响应用层。 |

## 4. 硬件/外设/协议要点

| 要点 | 说明 |
|---|---|
| PB10/PB11 | I2C2 的 SCL/SDA。 |
| MPU6050 | 接线与软件 I2C 保持一致。 |
| OLED | 显示读取结果。 |

## 5. 配置步骤或实验流程

1. 移除 MyI2C.c/.h 和 include。
2. 开启 GPIOB、I2C2 时钟。
3. PB10/PB11 配复用开漏。
4. 配置并使能 I2C2。
5. 写：START -> 地址写 -> 寄存器地址 -> 数据 -> STOP。
6. 读：START -> 地址写 -> 寄存器地址 -> repeated START -> 地址读 -> 数据 -> STOP。

## 6. 代码/函数要点

| I2C_CheckEvent | 按 EV 事件推进。 |
| MPU6050_WriteReg / ReadReg | 函数名保持，内部改硬件 I2C。 |

## 8. 常见坑

- SCL/SDA 不能互换，也不能任意换脚。
- 工程文件和磁盘文件要同步整理。
- 卡在事件等待时先查地址、接线、上拉、GPIO 模式。
