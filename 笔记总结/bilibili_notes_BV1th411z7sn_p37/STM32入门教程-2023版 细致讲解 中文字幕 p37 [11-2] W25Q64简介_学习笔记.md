## 3. 核心概念

| 概念 | 字幕整理后的含义 |
|---|---|
| 非易失存储 | 断电后数据保留。 |
| JEDEC ID | 验证 SPI 通信和芯片型号。 |
| 页编程 | 写入受页边界限制。 |
| 扇区擦除 | 写入前通常要擦除目标区域。 |
| 状态寄存器 | BUSY 表示忙，WEL 表示写使能锁存。 |

## 4. 硬件/外设/协议要点

| 要点 | 说明 |
|---|---|
| W25Q64 模块 | 通过 SPI 与 STM32 连接。 |
| CS/SCK/MOSI/MISO | 按模块与 STM32 对应连接。 |
| OLED | 显示 ID 和读写结果。 |

## 5. 配置步骤或实验流程

1. 读 ID 验证芯片。
2. 写入前 Write Enable。
3. 必要时擦除扇区。
4. Page Program 写入地址和数据。
5. 等待 BUSY 清零。
6. Read Data 读回验证。

## 8. 常见坑

- Flash 不是 RAM，写入前要考虑擦除。
- 擦除粒度较大，会影响整扇区。
- 跨页写入要拆分。
