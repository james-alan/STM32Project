## 一、编码器接口概述

### 1.1 为什么需要编码器接口

| 方案 | 实现方式 | 缺点 |
|------|---------|------|
| 外部中断计次 | 中断里手动 `++` / `--` | 高速时频繁中断，浪费CPU |
| **编码器接口（硬件）** | 定时器硬件自动计次 | ✅ 解放CPU，零软件开销 |

> 编码器接口本质上是一个**带方向控制的外部时钟**——自动控制CNT的自增/自减。

### 1.2 资源限制

- 每个**高级定时器**和**通用定时器**都有1个编码器接口
- C8T6只有TIM1/2/3/4 → 最多接4个编码器
- 接了4个编码器就没有多余定时器可用

## 二、正交编码器（Quadrature Encoder）

### 2.1 信号特征

```
正转(CW):             反转(CCW):
A: ┌─┐  ┌─┐  ┌─      A: ┌─┐  ┌─┐  ┌─
   │ │  │ │  │           │ │  │ │  │
B:   ┌─┐  ┌─┐  ┌      B: ┌─┐  ┌─┐  ┌─
                           ↑
   A提前B 90°              A滞后B 90°
```

- A/B两路方波，相位差90°
- 转速↑ → 频率↑；转向 → A/B相位关系判断

### 2.2 正交信号的优势

| 优势 | 说明 |
|------|------|
| **精度翻倍** | A/B相都可计次，频率提高一倍 |
| **抗噪声** | 单路连续跳变 → 计数加减抵消 → 值不变 |

### 2.3 方向判断逻辑

| 边沿事件 | 另一相状态（正转） | 另一相状态（反转） |
|---------|-----------------|-----------------|
| A上升沿 | B = **低** | B = **高** |
| A下降沿 | B = **高** | B = **低** |
| B上升沿 | A = **高** | A = **低** |
| B下降沿 | A = **低** | A = **高** |

## 三、电路结构与工作模式

### 3.1 信号路径

```
编码器 A相 → GPIO → CH1 → 滤波器+极性选择 → TI1FP1 ─┐
编码器 B相 → GPIO → CH2 → 滤波器+极性选择 → TI2FP2 ─┤
                                                      ↓
                                                编码器接口
                                                      ↓
                                                控制 CNT 自增/自减
```

- 编码器接口**借用了输入捕获的CH1和CH2**
- CH3/CH4与编码器无关
- 内部时钟(72MHz)和计数方向设置均被**编码器接口托管**，不再使用

### 3.2 三种工作模式

| 模式 | 计数边沿 | 精度 | 用途 |
|------|---------|------|------|
| 仅在TI1计数 | 仅A相上下沿 | 低 | 特殊需求 |
| 仅在TI2计数 | 仅B相上下沿 | 低 | 特殊需求 |
| **TI1+TI2都计数** | A/B相上下沿 | **最高**（默认） | **推荐** |

### 3.3 极性选择

在编码器模式下，`TIM_ICPolarity_Rising` / `Falling` 的含义改变：

| 参数 | 编码器模式含义 |
|------|--------------|
| `Rising` | 高低电平极性**不反转**（直通） |
| `Falling` | 高低电平极性**反转**（过非门） |

> 极性弄反了？换AB接线或改任一通道极性即可反转方向。

## 四、计数值处理——负数技巧

```c
// CNT是16位无符号数
// ARR设为65535（满量程）
// 初始 CNT = 0

正转：0 → 1 → 2 → 3 ...       // 正常自增
反转：0 → 65535 → 65534 ...   // 自减产生补码

// 强制转换为有符号数
int16_t speed = (int16_t)TIM_GetCounter(TIM3);
// 65535 → -1, 65534 → -2, ...
```

## 五、库函数

```c
void TIM_EncoderInterfaceConfig(
    TIM_TypeDef* TIMx,          // 定时器
    uint16_t TIM_EncoderMode,   // 模式: TI1/TI2/TI12
    uint16_t TIM_IC1Polarity,   // CH1极性
    uint16_t TIM_IC2Polarity    // CH2极性
);
```

| 参数 | 选项 |
|------|------|
| `TIM_EncoderMode` | `TIM_EncoderMode_TI1`, `TI2`, `TI12` |
| 极性 | `TIM_ICPolarity_Rising`(不反转), `Falling`(反转) |

## 六、关键要点总结

1. **编码器接口 = 带方向的外部时钟**，硬件自动控制CNT自增/自减
2. **借用了CH1和CH2**，编码器A/B相必须接定时器的CH1和CH2引脚
3. **内部时钟被托管**，TIM_TimeBaseInit中的时钟分频/计数方向不再生效
4. **ARR建议65535**（满量程），利用补码特性轻松得负数
5. **使用TI1+TI2模式**精度最高
6. **正交信号天然抗噪声**：单路毛刺导致加减抵消
7. 换AB相接线或反转任一通道极性 = 翻转计数方向
