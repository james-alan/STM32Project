## 2. 本节目标

理解 Unix 时间戳，并把它作为 RTC 日期时间换算基础。

## 3. 核心概念

| 概念 | 字幕整理后的含义 |
|---|---|
| RTC | 持续计数的实时时钟。 |
| Unix 时间戳 | 从固定起点累计的秒数。 |
| BKP | 复位或主电源掉电后保留少量数据。 |
| VBAT | 备用电源维持备份域和 RTC。 |
| 日期换算 | 秒数与年月日时分秒互转，需要处理闰年和月份。 |

## 4. 硬件/外设/协议要点

| 要点 | 说明 |
|---|---|
| VBAT | 视频用 3.3V 模拟备用电池。 |
| OLED | 显示日期、时间、时间戳和预分频计数。 |
| 按键 | BKP 例程中触发写入。 |

## 5. 配置步骤或实验流程

1. 用秒计数表示时间。
2. 把年月日时分秒转换为总秒数。
3. 显示时把总秒数反算为日期时间。
4. 通过复位和断主电源验证保持。

## 8. 常见坑

- RTC 要保证复位和掉电后继续计时。
- BKP 不是完全非易失，需 VBAT。
- 时间戳换算要处理闰年。
