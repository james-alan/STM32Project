## 2. 本节目标

学习 STM32 硬件 I2C 外设结构、功能和事件标志。

## 3. 核心概念

| 概念 | 字幕整理后的含义 |
|---|---|
| 硬件 I2C | 外设自动产生时序、发送地址、移位数据并管理标志。 |
| 事件 | 库函数用事件组合判断流程阶段。 |
| 主模式 | 课程中 STM32 作主机读写 MPU6050。 |
| 速率 | 常见 100 kHz 和 400 kHz。 |

## 4. 硬件/外设/协议要点

| 要点 | 说明 |
|---|---|
| I2C1/I2C2 | STM32F103C8T6 的硬件 I2C 资源。 |
| PB6/PB7 或 PB10/PB11 | 由外设复用决定。 |
| 复用开漏 | 硬件 I2C GPIO 模式。 |

## 5. 配置步骤或实验流程

1. 开启 I2C 和 GPIO 时钟。
2. GPIO 配为复用开漏。
3. 配置 I2C_InitTypeDef。
4. I2C_Cmd 使能外设。
5. 按事件流程 START、地址、数据、STOP。

## 6. 代码/函数要点

| 名称 | 用法/意义 |
|---|---|
| I2C_InitTypeDef | 硬件 I2C 初始化结构体。 |
| I2C_GenerateSTART / STOP | 控制起始和终止。 |
| I2C_Send7bitAddress | 发送地址和方向。 |
| I2C_CheckEvent | 等待事件。 |
| I2C_SendData / ReceiveData | 收发数据。 |

## 8. 常见坑

- 硬件 I2C 引脚固定，必须查表。
- 事件等待卡死时先查接线、地址、ACK。
- GPIO 要用复用开漏。
