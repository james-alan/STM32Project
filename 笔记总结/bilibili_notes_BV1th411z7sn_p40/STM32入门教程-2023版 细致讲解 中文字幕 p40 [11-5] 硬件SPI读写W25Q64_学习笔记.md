## 2. 本节目标

把 W25Q64 底层从软件 SPI 替换为硬件 SPI，保持上层 Flash 指令函数不变。

## 3. 核心概念

| 概念 | 字幕整理后的含义 |
|---|---|
| 底层替换 | GPIO 翻转改为 SPI 外设收发，上层 W25Q64 函数保持。 |
| 交换字节 | 硬件 SPI 仍可封装成 MySPI_SwapByte。 |
| 软件片选 | CS 继续由 GPIO 控制。 |

## 4. 硬件/外设/协议要点

| 要点 | 说明 |
|---|---|
| SPI1 引脚 | 使用硬件 SPI 的 SCK/MISO/MOSI。 |
| CS GPIO | 片选接普通 GPIO。 |
| W25Q64/OLED | 实验对象和显示。 |

## 5. 配置步骤或实验流程

1. 删除软件翻转 SCK/MOSI/MISO 的代码，保留 CS。
2. 开启 GPIO 和 SPI 时钟。
3. 配置 SPI 引脚复用和 MISO 输入。
4. 初始化并使能 SPI。
5. SwapByte 中写 DR，等待 RXNE 后读回。
6. 运行 W25Q64_ReadID、擦除、写入、读回验证。

## 8. 常见坑

- 不要让错误 NSS 配置影响软件片选。
- ID 读错先查 MISO/MOSI、引脚复用和模式。
- 读写顺序要保证收发完整。
