## 一、STM32三种开发方式

| 方式 | 特点 | 推荐度 |
|------|------|--------|
| **寄存器** | 直接操作寄存器，代码最底层 | ❌ 不推荐（太繁琐） |
| **标准库（库函数）** | ST官方封装函数间接操作寄存器 | ✅ **本课程使用** |
| **HAL库** | 图形化配置+封装，快速上手 | ⚠️ 隐藏底层，学完标准库再了解 |

## 二、新建工程完整流程（6步）

### 步骤总览

```
Step 1: 建立工程文件夹 → Keil新建工程 → 选择型号
Step 2: 复制固件库文件到工程文件夹
Step 3: Keil中建立分组 → 添加文件到分组
Step 4: 工程选项 → C/C++ → Include Paths（声明头文件路径）
Step 5: 工程选项 → C/C++ → Define（定义USE_STDPERIPH_DRIVER）
Step 6: 工程选项 → Debug → 选择ST-Link → Flash Download勾选Reset and Run
```

### 2.1 详细文件分类

```
工程文件夹
├── start/          ← 启动文件+系统文件（不需修改）
│   ├── startup_stm32f10x_md.s  ← 启动文件（汇编，MD=中容量）
│   ├── stm32f10x.h             ← 外设寄存器描述（头文件）
│   ├── system_stm32f10x.c/h    ← 系统时钟配置（72MHz）
│   └── core_cm3.c/h            ← 内核寄存器描述
├── library/        ← 库函数文件（不需修改）
│   ├── src/ 下所有 .c 文件      ← 外设库函数源文件
│   └── inc/ 下所有 .h 文件      ← 外设库函数头文件
└── user/           ← 用户文件（需要修改）
    ├── main.c                   ← 主函数
    ├── stm32f10x_conf.h         ← 头文件包含配置
    ├── stm32f10x_it.c/h         ← 中断服务函数
    └── ...（可自定义模块文件）
```

### 2.2 启动文件选择

| 芯片类型 | Flash大小 | 启动文件后缀 |
|---------|-----------|-------------|
| STM32F100（超值型） | 16-32K | startup_stm32f10x_ld_vl.s |
| | 64-128K | startup_stm32f10x_md_vl.s |
| STM32F101/102/103 | 16-32K | startup_stm32f10x_ld.s |
| | **64-128K** ← C8T6 | **startup_stm32f10x_md.s** |
| | 256-512K | startup_stm32f10x_hd.s |
| STM32F105/107（互联型） | — | startup_stm32f10x_cl.s |

> C8T6 = F103 + 64K Flash → 选 **md**（Medium Density）

### 2.3 Keil设置要点

| 设置项 | 路径 | 值 |
|--------|------|-----|
| Include Paths | C/C++ → Include Paths | start/ library/ user/ 三个文件夹路径 |
| Define | C/C++ → Define | `USE_STDPERIPH_DRIVER` |
| Debugger | Debug | ST-Link Debugger |
| Reset and Run | Debug → Settings → Flash Download | ✅ 勾选 |

## 三、寄存器 vs 库函数 对比（以点灯为例）

### 3.1 寄存器方式

```c
// Step 1: 使能GPIOC时钟（RCC_APB2ENR）
RCC->APB2ENR = 0x00000010;

// Step 2: 配置PC13为推挽输出（GPIOC_CRH）
GPIOC->CRH = 0x00300000;

// Step 3: 输出低电平（GPIOC_ODR）——灯亮
GPIOC->ODR = 0x00000000;

// 输出高电平——灯灭
GPIOC->ODR = 0x00002000;
```

**缺点**：
- 需要反复查手册确认每个bit含义
- 直接赋值会覆盖其他位（需用 `|=` `&=` 操作避免）
- 代码不直观

### 3.2 库函数方式

```c
// Step 1: 使能GPIOC时钟
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOC, ENABLE);

// Step 2: 配置PC13为推挽输出
GPIO_InitTypeDef GPIO_InitStructure;
GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;   // 推挽输出
GPIO_InitStructure.GPIO_Pin = GPIO_Pin_13;         // 13号引脚
GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;  // 50MHz
GPIO_Init(GPIOC, &GPIO_InitStructure);

// Step 3: 输出电平
GPIO_SetBits(GPIOC, GPIO_Pin_13);    // 高电平→灯灭
GPIO_ResetBits(GPIOC, GPIO_Pin_13);  // 低电平→灯亮
```

**优点**：
- 语义明确，无需查手册
- 自动使用 `|=` `&=` 操作，不影响其他位
- 参数有自动补全提示

## 四、工程架构解析

### 4.1 程序执行流程

```
上电/复位
    ↓
启动文件 (startup_stm32f10x_md.s)
    ↓ 复位中断
SystemInit()  ← system_stm32f10x.c（配置时钟72MHz）
    ↓
main()        ← main.c（用户代码入口）
    ↓
while(1) 死循环 ← 单片机永不停止
```

### 4.2 文件角色

| 文件 | 角色 |
|------|------|
| startup_xxx.s | 汇编启动文件，定义中断向量表 |
| system_stm32f10x.c | 配置系统时钟（PLL倍频→72MHz） |
| stm32f10x.h | 外设寄存器地址和位定义 |
| core_cm3.c/h | Cortex-M3内核寄存器定义 |
| stm32f10x_conf.h | 包含所有库函数头文件（条件编译） |
| stm32f10x_it.c/h | 中断服务函数定义 |
| 外设库函数.c/h | 各外设的封装函数（如gpio.c, rcc.c等） |

### 4.3 头文件包含链

```
main.c
  └── #include "stm32f10x.h"
        └── (末尾) #include "stm32f10x_conf.h"
              ├── #include "stm32f10x_gpio.h"
              ├── #include "stm32f10x_rcc.h"
              ├── #include "stm32f10x_tim.h"
              └── ... (所有外设头文件)
```

> 只需 `#include "stm32f10x.h"` 就能使用所有库函数！

## 六、关键要点总结

1. **本课程使用标准库（库函数）开发**，寄存器太繁琐，HAL库先不推荐
2. **新建工程6步流程**：建文件夹→复制文件→添加分组→声明路径→定义宏→配置调试器
3. **启动文件选MD**（C8T6=中容量=64K Flash）
4. **所有文件必须复制到工程文件夹内**，保持工程独立性
5. **必须定义 `USE_STDPERIPH_DRIVER`**，否则库函数不生效
6. **工程选项Debug选ST-Link**，勾选Reset and Run可自动复位
7. **程序启动链**：启动文件 → SystemInit() → main()
