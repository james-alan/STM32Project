## 二、安装 Keil 5 MDK

### 2.1 注意事项

| 项目 | 说明 |
|------|------|
| 安装路径 | 不可含中文或特殊字符 |
| C51共存 | 可选C51安装目录，两个软件可共存 |
| 路径选择 | 建议D盘根目录新建 `Keil5` 文件夹 |

### 2.2 Keil C51 vs MDK

```
Keil 5 C51  → 51系列单片机
Keil 5 MDK  → ARM系列单片机（STM32等）
```

- 两者是Keil的不同子系列，可安装在同一目录下共存
- 仅装MDK也可以正常开发STM32

## 三、器件支持包（Pack）

### 3.1 为什么需要

- Keil 5之后，芯片支持包与主软件分离
- 开发哪种芯片就装哪个包，节省空间
- **不装包则新建工程时看不到对应芯片型号**

### 3.2 离线安装（推荐）

```
安装包 → 找到 .pack 文件 → 双击安装
```

本课程需要：`Keil.STM32F1xx_DFP.x.x.x.pack`

### 3.3 在线安装（备选）

```
Keil → 绿色Pack Installer按钮 → 联网获取列表 → 选芯片 → Install
```

- 优点：支持所有ARM芯片型号
- 缺点：网速慢，等待时间长

> 国产兼容芯片：GD32（GigaDevice）、MM32（MindMotion），基本兼容STM32F103C8T6。

## 四、软件注册

### 4.1 注册流程

| 步骤 | 操作 |
|------|------|
| 1 | **右键以管理员身份运行** Keil |
| 2 | File → License Management → 复制CID |
| 3 | 打开注册机 → 粘贴CID → Target选**ARM** → Generate |
| 4 | 复制生成的序列码 → 回到Keil → Add LIC |
| 5 | 看到有效期显示至2032年即成功 |

### 4.2 常见问题

| 问题 | 原因/解决 |
|------|----------|
| Add LIC报错 | 没有以管理员身份运行（必须右键→管理员运行） |
| 注册机消失 | 被杀毒软件删除，需关闭杀软重新解压 |
| 注册C51 | Target选C51，其余步骤相同 |

## 五、ST-Link 驱动

### 5.1 安装方法

```
设备管理器 → 查看ST-Link状态
├── 无感叹号 → 已安装，跳过
└── 有感叹号/在其他设备 → 需安装驱动
```

驱动路径：`Keil安装目录\ARM\STLink\USBDriver\dpinst_amd64.exe`

### 5.2 其他调试器

| 调试器 | 驱动路径 | 连接方式 |
|--------|---------|---------|
| ST-Link | STLink\USBDriver\ | SWD（2线） |
| J-Link | Segger\ | SWD/JTAG |
| U-Link | Keil自带 | SWD/JTAG |

## 六、USB转串口驱动（CH340）

### 6.1 安装

```
插上USB转串口模块 → 设备管理器查看端口
├── 正常识别 → 已安装
└── 感叹号 → 需安装 CH340 驱动
```

驱动：资料包 → 工具软件 → USB转串口CH340驱动 → 双击安装

### 6.2 验证

设备管理器 → 端口(COM和LPT) → 出现 `USB-SERIAL CH340 (COMx)` 无感叹号即成功。
