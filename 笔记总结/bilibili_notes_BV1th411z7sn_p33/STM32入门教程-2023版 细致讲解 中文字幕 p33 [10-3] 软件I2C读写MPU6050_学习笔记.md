## 2. 本节目标

用 GPIO 软件模拟 I2C 时序，实现 MPU6050 寄存器读写。

## 3. 核心概念

| 概念 | 字幕整理后的含义 |
|---|---|
| 软件 I2C | 不用硬件外设，直接用 GPIO 翻转模拟协议。 |
| 开漏输出 | 输出 0 拉低，输出 1 释放总线。 |
| 分层封装 | MyI2C 负责时序，MPU6050 负责寄存器语义。 |
| 读写寄存器 | 写为地址+寄存器+数据，读为先定位寄存器再读。 |

## 4. 硬件/外设/协议要点

| 要点 | 说明 |
|---|---|
| PB10/PB11 | 视频为兼容后续硬件 I2C，软件 I2C 也接在这些脚。 |
| MPU6050 | SCL/SDA 接对应引脚。 |
| OLED | 显示 ID 和六轴数据。 |

## 5. 配置步骤或实验流程

1. MyI2C_Init 初始化 GPIO 开漏输出。
2. Start/Stop 产生起始和终止。
3. SendByte 后读取 ACK。
4. ReceiveByte 后按需要发送 ACK/NACK。
5. 封装 MPU6050_WriteReg 和 ReadReg。
6. GetData 连续读取并组合六轴数据。

## 6. 代码/函数要点

| 名称 | 用法/意义 |
|---|---|
| MyI2C_Start / Stop | 软件时序基础。 |
| MyI2C_SendByte / ReceiveByte | 逐位操作 SDA/SCL。 |
| MPU6050_WriteReg / ReadReg | 寄存器读写接口。 |
| MPU6050_GetData | 读取 AccX/Y/Z 和 GyroX/Y/Z。 |

## 8. 常见坑

- 软件 I2C 可换脚，但代码端口和引脚必须同步改。
- ACK 方向要分清。
- SCL/SDA 变化顺序不能乱。
