## 一、课程定位

### 1.1 前置知识建议
- **推荐先学51单片机**：STM32相比51单片机有一定难度，零基础同学建议先看51单片机入门教程
- 本课程会经常拿51单片机来举例比较，有51基础学起来更加轻松

### 1.2 教学特点：程序纯手打，手把手教学
| 教学方式 | 优点 | 缺点 |
|---------|------|------|
| 对着现成代码讲 | 省时间 | 听完不知道从哪里下手 |
| **一步步演示（本课程）** | 至少能把现象做出来，对每一步理解更深刻 | 代码量大，耗时长 |

- 固定代码（延时函数、显示屏驱动等）会直接提供
- 关键部分代码亲自敲出来，演示工程建立和程序调试全过程

## 二、硬件平台

### 2.1 核心架构
```
┌──────────────────────────────────────────┐
│              面包板 (Breadboard)           │
│  ┌─────────────┐    ┌──────────────┐      │
│  │ STM32最小系统板│    │ 0.96寸OLED屏  │      │
│  │  (STM32F103) │    │  (4引脚版本)   │      │
│  └─────────────┘    └──────────────┘      │
│     两侧: LED / 按键                        │
│     杜邦线连接: 蜂鸣器、传感器等模块           │
└──────────────────────────────────────────┘
           │
    ┌──────┴──────┐
    │  ST-Link    │  ← 插电脑，用于下载程序和供电
    └─────────────┘
```

### 2.2 面包板 vs 成品开发板

| 对比维度 | 面包板方案 | 成品开发板 |
|---------|-----------|-----------|
| 电路学习 | ✅ 有利于理解硬件连接 | ❌ 屏蔽了电路细节 |
| 引脚灵活性 | ✅ 任意连接，无冲突 | ❌ 引脚固定，可能冲突 |
| 接线复杂度 | ⚠️ 需细心，可能接错 | ✅ 即插即用 |
| 调试难度 | ⚠️ 程序+硬件双重排查 | ✅ 只需排查程序 |

### 2.3 所需硬件设备清单

| 类别 | 设备 | 用途 |
|------|------|------|
| **核心套件** | STM32面包板入门套件 | 包含面包板、最小系统板、跳线、杜邦线等 |
| **电脑** | Windows电脑 | Keil MDK开发环境 |
| **调试工具** | 万用表 | 检查电路连接、排查接触不良 |
| | 示波器/逻辑分析仪（可选） | 观测PWM波形、通信协议时序 |
| | 镊子、剪刀 | 方便面包板插拔线 |

## 四、硬件模块概览

### 4.1 基础模块

| 模块 | 型号/规格 | 实验用途 |
|------|----------|---------|
| STM32最小系统板 | STM32F103C8T6 | 核心芯片 |
| OLED显示屏 | 0.96寸 4引脚（注意不是7引脚） | 参数/变量显示调试 |
| LED | 多种颜色 | 点灯实验 |
| 按键 | 2引脚小型按键 | 输入控制实验 |
| 有源蜂鸣器 | 内置振荡源 | 上电即响，类似点灯 |
| 电位器 | 蓝色多圈 | AD转换实验 |

### 4.2 通信/下载模块

| 模块 | 通信接口 | 用途 |
|------|---------|------|
| ST-Link | SWD | 下载程序 + 供电 |
| USB转串口 | UART | STM32与电脑串口通信 |

### 4.3 传感器模块

| 模块 | 输出信号 | 对应实验 |
|------|---------|---------|
| 光敏电阻模块 | 模拟输出 + 数字输出 | GPIO读取 / AD实验 |
| 热敏电阻模块 | 模拟输出 + 数字输出 | GPIO读取 / AD实验 |
| 对射式红外模块 | 数字脉冲 | 计次 / 配合编码盘测速 |
| 反射式红外模块 | 数字信号 | 循迹（识别地面颜色变化） |

### 4.4 进阶外设模块

| 模块 | 通信接口 | 学习目标 |
|------|---------|---------|
| W25Q64 Flash存储 | **SPI** | 学习SPI总线通信 |
| MPU6050 陀螺仪+加速度计 | **I2C** | 学习I2C总线通信，姿态检测 |
| 旋转编码器 | 正交方波 | TIM编码器接口（测速/方向） |
| 直流电机 + TB6612驱动 | PWM | PWM调速实验 |
| SG90 舵机 | PWM | PWM角度控制（机器人/机械臂关节） |

### 4.5 面包板接线工具

| 工具 | 特点 | 适用场景 |
|------|------|---------|
| 专用跳线（短） | 贴板走线，整齐 | 长时间固定接线 |
| 飞线（长） | 灵活挪动 | 经常调整的接线 |
| 杜邦线（公母/母母） | 带插头 | 插接模块 |

## 五、关键要点总结

1. **有51基础最好**，没有的话先补51再学STM32会更顺畅
2. **课程是"手打代码"风格**，不是念PPT——跟着敲就能出效果
3. **硬件用面包板搭建**，灵活但需要细心接线
4. **OLED屏幕作为调试窗口**，函数接口与51版本一致，降低学习成本
5. **Keil MDK ≠ Keil C51**，两个软件独立安装，互不冲突
6. **示波器非必需**，没有也不影响现象呈现，有则锦上添花
