## 2. 本节目标

认识 MPU6050 的传感器功能、寄存器组织和常用配置。

## 3. 核心概念

| 概念 | 字幕整理后的含义 |
|---|---|
| 六轴数据 | 三轴加速度和三轴角速度。 |
| 寄存器映射 | 配置和数据都通过寄存器地址读写。 |
| WHO_AM_I | 读出设备 ID，常见 0x68。 |
| 量程 | 影响原始值到物理量的换算比例。 |
| 高低字节 | 数据分高 8 位和低 8 位，需要合成为 int16_t。 |

## 4. 硬件/外设/协议要点

| 要点 | 说明 |
|---|---|
| VCC/GND | 模块供电和共地。 |
| SCL/SDA | I2C 通信线。 |
| AD0 | 影响地址低位。 |

## 5. 配置步骤或实验流程

1. 读取 WHO_AM_I 判断通信。
2. 写电源管理寄存器唤醒模块。
3. 配置加速度计和陀螺仪量程。
4. 连续读取输出寄存器。
5. 高低字节合并后显示。

## 6. 代码/函数要点

| 名称 | 用法/意义 |
|---|---|
| MPU6050_Init | 初始化配置寄存器。 |
| MPU6050_ReadReg / WriteReg | I2C 寄存器读写封装。 |
| MPU6050_GetData | 读取六轴原始数据。 |

## 8. 常见坑

- 上电后可能处于睡眠，需要唤醒。
- 高低字节要按有符号 16 位处理。
- 不同批次 ID 可能略有差异，要结合数据是否正常判断。
