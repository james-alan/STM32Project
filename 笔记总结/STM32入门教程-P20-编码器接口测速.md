## 一、硬件接线

| 编码器引脚 | STM32引脚 | 说明 |
|-----------|----------|------|
| VCC | 3.3V | 电源正 |
| GND | GND | 电源负 |
| A相 | **PA6** (TIM3_CH1) | 可交换 |
| B相 | **PA7** (TIM3_CH2) | 可交换 |

> A/B相可互换（反转方向），但必须是定时器对应的CH1/CH2引脚！

---

## 二、初始化流程（5步）

```
Step 1: RCC使能时钟（GPIOA + TIM3）
Step 2: GPIO初始化（PA6/PA7 → 上拉输入）
Step 3: 时基单元配置（PSC=0不分频, ARR=65535满量程）
Step 4: 输入捕获滤波+极性配置（CH1/CH2）
Step 5: 编码器接口配置 → TIM_Cmd启动
```

### 2.1 完整初始化代码

```c
#include "stm32f10x.h"

void Encoder_Init(void)
{
    // Step 1: 开启时钟
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM3, ENABLE);
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);
    
    // Step 2: 配置GPIO（PA6=CH1, PA7=CH2 → 上拉输入）
    GPIO_InitTypeDef GPIO_InitStructure;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;       // 上拉输入
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_6 | GPIO_Pin_7;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOA, &GPIO_InitStructure);
    
    // Step 3: 时基单元（内部时钟无用，但仍需初始化）
    TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;
    TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up;  // 被托管，无效
    TIM_TimeBaseStructure.TIM_Period = 65536 - 1;    // ARR=65535
    TIM_TimeBaseStructure.TIM_Prescaler = 1 - 1;      // PSC=0 不分频
    TIM_TimeBaseStructure.TIM_RepetitionCounter = 0;
    TIM_TimeBaseInit(TIM3, &TIM_TimeBaseStructure);
    
    // Step 4: 输入捕获通道配置（仅滤波器和极性有用）
    TIM_ICInitTypeDef TIM_ICInitStructure;
    TIM_ICStructInit(&TIM_ICInitStructure);            // 先赋默认值
    TIM_ICInitStructure.TIM_Channel = TIM_Channel_1;
    TIM_ICInitStructure.TIM_ICFilter = 0x0F;           // 滤波器
    TIM_ICInitStructure.TIM_ICPolarity = TIM_ICPolarity_Rising;
    TIM_ICInit(TIM3, &TIM_ICInitStructure);
    
    TIM_ICInitStructure.TIM_Channel = TIM_Channel_2;
    TIM_ICInit(TIM3, &TIM_ICInitStructure);
    
    // Step 5: 配置编码器接口
    TIM_EncoderInterfaceConfig(TIM3,
        TIM_EncoderMode_TI12,              // A/B相都计数
        TIM_ICPolarity_Rising,             // CH1不反转
        TIM_ICPolarity_Rising);            // CH2不反转
    
    // 启动定时器
    TIM_Cmd(TIM3, ENABLE);
}
```

### 2.2 输入模式选择原则

| 外部模块默认电平 | 选择模式 |
|---------------|---------|
| 默认高 → | **上拉输入**（最常用） |
| 默认低 → | 下拉输入 |
| 不确定/信号弱 → | 浮空输入（无上下拉影响） |

## 三、读取编码器值

### 3.1 测量位置（直接读CNT）

```c
int16_t Encoder_Get(void)
{
    return (int16_t)TIM_GetCounter(TIM3);
    // uint16 → int16: 65535 → -1, 利用补码
}
```

### 3.2 测量速度（测频法：读后清零）

```c
int16_t Encoder_Get(void)
{
    int16_t temp = (int16_t)TIM_GetCounter(TIM3);
    TIM_SetCounter(TIM3, 0);   // 读后清零
    return temp;                // 返回闸门时间内的脉冲数 = 速度
}
```

### 3.3 闸门时间方案

| 方案 | 实现 | 适用场景 |
|------|------|---------|
| **Delay延时空循环** | `Delay_ms(1000); speed = Encoder_Get();` | 简单测试 |
| **定时中断** | TIM中断中 `speed = Encoder_Get()` | ✅ 推荐（不阻塞主循环） |

```c
// 推荐：定时中断方式
int16_t Speed;  // 全局变量

void TIM2_IRQHandler(void)  // 定时器中断，如1秒一次
{
    if (TIM_GetITStatus(TIM2, TIM_IT_Update) == SET)
    {
        Speed = Encoder_Get();               // 读速度
        TIM_ClearITPendingBit(TIM2, TIM_IT_Update);
    }
}

int main(void)
{
    Encoder_Init();
    Timer_Init();  // TIM2定时中断
    
    while (1)
    {
        OLED_ShowSignedNum(1, 7, Speed, 5);  // 主循环快速刷新显示
    }
}
```

## 四、方向调整

| 方法 | 操作 | 说明 |
|------|------|------|
| **硬件换线** | 交换A/B相接线 | 最简单 |
| **软件改极性** | 任一通道 `Rising`→`Falling` | 改一个即可 |
| **软件两通道都改** | 两个都反 → 方向不变 | 白改 |

## 五、实测现象

| 操作 | CNT变化 | Speed显示 |
|------|---------|----------|
| 右转慢 | 自增（少量） | 正数（小） |
| 右转快 | 自增（大量） | 正数（大） |
| 左转慢 | 自减（少量） | 负数（小） |
| 左转快 | 自减（大量） | 负数（大） |
| 停止 | 不变 | 0 |
| 左转过零 | 0→65535→... | 负数（补码自动转换） |

> C8T6编码器每转动一格（段落感），A/B相各产生一个脉冲（上升+下降沿），共+4或-4。

## 六、关键要点总结

1. **编码器A/B相必须接CH1/CH2**（看引脚定义查对应关系）
2. **ARR设65535满量程**，PSC=0不分频
3. **uint16→int16强制转换**利用补码得负数
4. **测速=测频法**：定时读取CNT→清零→值=闸门内脉冲数
5. **推荐定时中断读速度**，不阻塞主循环
6. **TIM_ICStructInit先赋默认值**，防止结构体未完整配置出问题
7. 极性配置在`TIM_EncoderInterfaceConfig`中设就行，ICInit中的极性会被覆盖
8. 换AB相线 = 翻转方向，最简单
