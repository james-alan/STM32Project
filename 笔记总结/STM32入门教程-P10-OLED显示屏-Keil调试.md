## 一、OLED接线

```
OLED (4引脚)        STM32面包板
    GND    ←──→    GND供电排
    VCC    ←──→    3.3V供电排
    SCL    ←──→    PB8
    SDA    ←──→    PB9
```

- OLED固定在面包板右下角，长期插着方便调试
- 可用GPIO口直接供电（OLED功率小），但正式项目建议用电源

## 三、显示函数全览

| 函数 | 参数 | 示例 |
|------|------|------|
| `OLED_Init()` | 无 | 初始化（必须最先调用） |
| `OLED_Clear()` | 无 | 清屏 |
| `OLED_ShowChar(行, 列, 'A')` | 行1~4, 列1~16 | `OLED_ShowChar(1, 1, 'A')` |
| `OLED_ShowString(行, 列, "Hello!")` | 同上 | `OLED_ShowString(1, 3, "Hello World!")` |
| `OLED_ShowNum(行, 列, 12345, 5)` | len=显示位数 | 长度>数字→前面补0 |
| `OLED_ShowSignedNum(行, 列, -66, 3)` | 带正负号 | 显示 -066 |
| `OLED_ShowHexNum(行, 列, 0xA5A5, 4)` | 十六进制 | 显示 A5A5 |
| `OLED_ShowBinNum(行, 列, 0xA5A5, 16)` | 二进制 | 显示 1010010110100101 |

### 显示长度规则

```
参数长度 > 数字位数  → 前面补0（如 len=6 → 012345）
参数长度 < 数字位数  → 高位截断（如 len=4 → 2345）
```

> C语言不支持直接写二进制数（奇怪但事实），只能写十六进制替代。

## 四、Keil调试模式

### 4.1 进入与基本操作

| 操作 | 按钮/方法 |
|------|----------|
| 进入调试 | 🔍+d 图标（或 Ctrl+F5） |
| 复位 | RST 按钮 |
| 全速运行 | ▶ 按钮 |
| 停止 | ⏹ 按钮 |
| 单步运行 | 进入函数 / 跳过函数 / 跳出函数 / 运行到光标 |

### 4.2 关键功能

| 功能 | 路径 | 用途 |
|------|------|------|
| **断点** | 代码左侧灰色区域点击 | 程序运行到断点自动停 |
| **Watch窗口** | 符号窗口→右键变量→Add to Watch | 实时查看变量值变化 |
| **外设寄存器** | Peripherals菜单→System Viewer | 查看GPIO/TIM等所有外设寄存器 |
| **反汇编窗口** | 工具栏按钮 | C代码对应的汇编指令 |

### 4.3 实战演示

```
1. 编译通过 → 插好ST-Link → 点击🔍d进入调试
2. 左侧点灰色区域设断点（如 while(1) 内）
3. 全速运行 → 程序停在断点
4. 打开 Watch 窗口 → 添加变量 → 单步运行看值变化
5. Peripherals → GPIOA → ODR → 实时看输出寄存器变化
6. STM32板子上LED同步变化（硬件在线调试）
```

> **注意**：调试模式下不能直接改代码，需先退出→编译→重新进入。

## 五、三种调试方式对比

| 方式 | 优势 | 适用场景 |
|------|------|---------|
| **OLED显示** | 始终在线，覆盖刷新 | 日常调试，显示少量变量 |
| **串口调试** | 电脑端功能强大 | 大量数据/图表/日志 |
| **Keil调试模式** | 最强大：单步/断点/寄存器/变量 | 疑难bug、逻辑追踪 |
