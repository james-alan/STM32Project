## 2. 本节目标

通过代码修改系统主频，并进入睡眠、停止、待机模式观察差异。

## 3. 核心概念

| 概念 | 字幕整理后的含义 |
|---|---|
| 主频修改 | 改变系统运行频率，会影响延时和外设时钟。 |
| 睡眠实验 | CPU 暂停，外设/中断可唤醒。 |
| 停止实验 | 高速时钟停止，醒来要恢复时钟。 |
| 待机实验 | 醒来从复位流程开始。 |

## 4. 硬件/外设/协议要点

| 要点 | 说明 |
|---|---|
| 按键 | 触发进入模式或唤醒。 |
| OLED | 显示频率、模式或计数。 |
| WKUP | 待机唤醒常用。 |

## 5. 配置步骤或实验流程

1. 修改系统时钟并验证显示/延时。
2. 睡眠：配置中断后 WFI。
3. 停止：配置唤醒，醒后重新配置系统时钟。
4. 待机：清除唤醒标志，设置唤醒引脚，进入待机。

## 6. 代码/函数要点

| 名称 | 用法/意义 |
|---|---|
| SystemInit / SetSysClock | 系统时钟配置。 |
| __WFI | 等待中断。 |
| PWR_EnterSTOPMode | 停止模式入口。 |
| PWR_EnterSTANDBYMode | 待机模式入口。 |
| RCC_GetFlagStatus | 判断相关标志。 |

## 8. 常见坑

- 改主频后延时和外设参数要复核。
- 停止醒后不恢复时钟会异常。
- 待机不是从原代码位置继续执行。
