## 技术踩坑
- ffmpeg 是 bijian ASR 和 pydub 的必要依赖，winget 安装后需手动加 PATH
- `videocaptioner process` 需要 LLM API key，只用 ASR 用 `transcribe` 子命令即可
- B站下载高清需要 cookie，不清情况下只能下到 360P，但音频 OK 用于 ASR
