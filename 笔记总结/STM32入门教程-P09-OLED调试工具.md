## 一、三种常用调试方法

| 方法 | 实现 | 优点 | 缺点 |
|------|------|------|------|
| **串口调试** | UART→电脑，串口助手显示 | 电脑端功能强大（图表、曲线、GUI） | 需要拖着电脑；只能流式打印 |
| **显示屏调试** ✅ | OLED直接接单片机 | 覆盖刷新；始终在线；可做人机界面 | 屏幕小，显示内容有限 |
| **Keil调试模式** | 单步运行、断点、查看寄存器/变量 | 功能最强大 | 需要连接调试器 |

> 本课程偏爱显示屏调试——不断变化的数据可以原地刷新，不用刷屏。

### 1.1 其他调试技巧

| 方法 | 做法 |
|------|------|
| **点灯调试法** | 在关键位置放点灯代码，验证程序是否执行到那里 |
| **注释调试法** | 注释掉新代码→逐行恢复→定位问题行；或注释一半测试另一半 |
| **对照法** | 拿能跑通的程序和你的对照，逐步替换定位差异 |

> 调试核心思想：缩小范围、控制变量、对比测试。

## 二、OLED介绍

### 2.1 什么是OLED

```
OLED = Organic Light Emitting Diode（有机发光二极管）
```

- 每个像素独立自发光，无需背光 → 省电
- 响应速度快 → 高刷新率，不阻塞主程序
- 宽视角 → 任何角度看都清晰
- 轻薄柔韧 → 折叠屏手机用OLED

### 2.2 0.96寸OLED模块参数

| 参数 | 值 |
|------|-----|
| 供电 | 3.3V ~ 5V |
| 通信协议 | **I2C**（4引脚版）/ SPI（7引脚版） |
| 分辨率 | **128×64** |
| 像素颜色 | 白色 / 蓝色 / 黄蓝双色 |

### 2.3 版本区分

| 版本 | 引脚数 | 通信协议 | 本课程使用 |
|------|--------|---------|-----------|
| 4引脚 | VCC, GND, SCL, SDA | I2C | ✅ |
| 7引脚 | VCC, GND, SCL, SDA, RES, DC, CS | SPI | ❌ |

> 本课程驱动用GPIO模拟I2C协议，SCL/SDA接任意GPIO口即可。

## 三、驱动函数概览（OLED.h）

### 3.1 屏幕坐标

```
         列0  列1  列2    ...    列15
       ┌────┬────┬────┬────┬────┐
行0    │    │    │    │    │    │
行1    │    │    │    │    │    │
行2    │    │    │    │    │    │
行3    │    │    │    │    │    │
       └────┴────┴────┴────┴────┘
       每个格子=8×16像素，共4行×16列
```

### 3.2 函数速查表

| 函数 | 功能 | 参数 |
|------|------|------|
| `OLED_Init()` | 初始化OLED | 无 |
| `OLED_Clear()` | 清屏 | 无 |
| `OLED_ShowChar(行, 列, 字符)` | 显示一个字符 | 行1~4, 列1~16 |
| `OLED_ShowString(行, 列, "字符串")` | 显示字符串 | 同上 |
| `OLED_ShowNum(行, 列, 数字, 长度)` | 显示无符号十进制数 | 长度=显示位数 |
| `OLED_ShowSignedNum(行, 列, 数字, 长度)` | 显示有符号十进制数 | 带正负号 |
| `OLED_ShowHexNum(行, 列, 数字, 长度)` | 显示十六进制数 | — |
| `OLED_ShowBinNum(行, 列, 数字, 长度)` | 显示二进制数 | — |

### 3.3 使用示例

```c
#include "OLED.h"

OLED_Init();                                    // 初始化
OLED_ShowChar(1, 1, 'A');                      // 1行1列显示 A
OLED_ShowString(1, 3, "Hello World!");         // 1行3列显示字符串
OLED_ShowNum(2, 1, 12345, 5);                  // 2行1列显示 12345
OLED_ShowSignedNum(2, 8, -66, 3);              // 2行8列显示 -066
OLED_ShowHexNum(3, 1, 0xA5A5, 4);              // 3行1列显示 A5A5
OLED_ShowBinNum(4, 1, 0xA5A5, 16);             // 4行1列显示二进制
```

### 3.4 现象展示

```
A
Hello World!
12345   -066
A5A5
1010010110100101
```

## 四、关键要点总结

1. **OLED 驱动函数接口与51单片机LCD驱动完全一致**，有51基础可无缝上手
2. 屏幕分辨率128×64，本驱动分4行×16列
3. 4引脚版用I2C协议（GPIO模拟），SCL/SDA接任意IO口
4. **建议用OLED调试**而非串口——覆盖刷新显示不断变化的数据更直观
5. 调试基本原则：缩小范围、控制变量、对比测试
6. 从下节开始，OLED会频繁用于显示变量值辅助调试
